# Gerald B. Folland — *Quantum Field Theory: A Tourist Guide for Mathematicians*

This is a style reference more than a direct source for the hydrogen calculation.

The useful habit is to identify the mathematical object before descending into physicists' coordinate notation.

For `pauli`, that means preferring explanations such as:

- Hilbert space before wavefunction coordinates;
- group action before integer labels;
- representation before a particular spherical-harmonic formula;
- self-adjoint operator before a formal differential expression;
- spectral decomposition before a list of eigenfunctions;
- invariant structure before coordinate-dependent formulas.

A formula is useful when it answers a question or gives a computable representation of an already identified object. It should not substitute for saying what the object is.

## Relevance to the hydrogen problem

Spherical harmonics are a good example of the desired order.

The conceptual object is an irreducible rotation representation, equivalently an eigenspace of the rotation-invariant Laplacian on the sphere. Only after choosing an axis and coordinates does one write a convenient basis using associated Legendre functions and an azimuthal phase.

Likewise, a Hamiltonian should first be identified as the generator of time evolution in the quantum theory, together with the domain that makes it a self-adjoint operator. The coordinate differential expression comes afterward.

The point is not to imitate Folland sentence by sentence. It is to preserve the distinction between an object and one notation for that object.
