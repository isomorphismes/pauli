# Gerald B. Folland — *Quantum Field Theory: A Tourist Guide for Mathematicians*

This is a style reference more than a direct source for the hydrogen calculation.

The useful habit is to identify the mathematical object before descending into physicists' coordinate notation.

For `laguerre`, that means preferring explanations such as:

- Hilbert space before wavefunction coordinates;
- group action before quantum-number tables;
- representation before a particular spherical-harmonic formula;
- self-adjoint operator before formal differential expression;
- spectral decomposition before a list of eigenfunctions;
- invariant structure before coordinate-dependent formulas.

A formula is useful when it answers a question or gives a computable representation of an already identified object. It should not substitute for saying what the object is.

This is especially important for spherical harmonics. The conceptual object is an eigenspace of the spherical Laplacian / an irreducible rotation representation. Associated Legendre polynomials are one coordinate expression for a convenient basis after choosing an axis.
