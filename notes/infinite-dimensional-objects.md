# Do not explain infinite-dimensional objects as enormous matrices

Avoid the pedagogical story in which finite-dimensional linear algebra is presented as the real object and an infinite-dimensional problem is explained by imagining a matrix with infinitely many entries.

That can be a useful stage in learning. It is not the presentation wanted here.

A Hilbert space, a function space, or a differential operator should be introduced directly as the object it is.

A matrix is what an operator looks like **after a basis has been chosen**. In an infinite-dimensional setting that coordinate representation may be useful for a computation, but it should not be mistaken for the definition or conceptual source of the operator.

Likewise, smoothness is not obtained by "filling in enough entries" of a matrix. Smoothness is regularity of functions, sections, maps, or solutions. When a differential operator forces additional regularity, explain the analytical reason.

For this project:

- functions are legitimate vectors without first being disguised as coordinate lists;
- operators act on function spaces directly;
- eigenfunctions are eigenvectors in those spaces;
- basis expansions are coordinate descriptions of functions;
- matrices appear when a chosen basis makes them useful;
- finite-dimensional analogy may clarify a point, but it should not be made foundational.

The purpose is not to advertise infinite-dimensional mathematics as more complicated linear algebra. It is usually cleaner to say what the space and operator actually are.
