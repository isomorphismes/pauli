The Hydrogen Atom

A point nucleus, three-dimensional space, rotations, and a linear state space already force much of the structure that chemistry books often present as a list of formulas and labels.

Start with a local question

Write one number at every point: temperature, membrane displacement, electric potential, or something else. At one point ask whether its value is above, below, or in balance with the values immediately around it.

That local comparison is what the operation later named the Laplacian measures.

On a line this is a second difference: how the first difference is itself changing. In ordinary three-dimensional coordinates, the same question is asked independently in three directions and the answers are added.

Δf = second change in x + second change in y + second change in z

A membrane is pulled by its neighbors. Its acceleration therefore depends on how it bends relative to those neighbors. The shapes that reproduce themselves while vibrating are its natural patterns.

Now put the same question on a sphere

A point nucleus has no preferred direction. Points at the same distance from it form a sphere. Before choosing an axis or introducing the usual integer labels, ask which angular patterns are preserved as families by rotations.

There is a concrete way to make those patterns. Start with ordinary homogeneous polynomials in x, y, and z. Keep only the ones whose local-balance measure is zero. Then restrict those polynomials to the unit sphere.

The Sage calculation literally takes the kernel of that operation. For degrees zero through three it finds the dimensions below.

So the familiar sequence 1, 3, 5, 7 is not a table we have to start by memorizing. It falls out of a small geometric question.

Where “spherical harmonic” enters

A function whose local-balance measure is zero is traditionally called harmonic. Restricting these homogeneous harmonic polynomials to a sphere produces the objects traditionally called spherical harmonics. The name comes after the construction.

Distance from the nucleus is a different question

Once an angular family is fixed, the remaining unknown depends only on distance from the nucleus. For a bound state, the equation itself tells us what behavior is allowed near the nucleus and far away.

Factor out the power forced near the origin and the exponential decay forced far away. What remains can be written as a power series. The calculator then asks what relation neighboring coefficients must satisfy.

next coefficient = 2[(inverse length)(current power + angular degree + 1) − 1] ÷ [(next power)(current power + 2 angular degree + 2)] × current coefficient

For a bound state the series has to stop. The stopping condition fixes the allowed inverse length and therefore the allowed energy. What remains is a finite polynomial.

Where “Laguerre” enters

After deriving these finite polynomials from the recurrence, the build asks Sage for the named generalized-Laguerre family and checks that the two differ only by an overall constant. The library function is an oracle, not the constructor.

Why thirty states appear before rendering

The first four bound-energy families contain 1 + 4 + 9 + 16 = 30 independent spatial states. Those counts come from adding the angular-family dimensions, not from a hard-coded orbital table.

The repository then checks the exact stationary equation, normalization and orthogonality, and lowers the resulting complex values to the runtime as magnitude + phase, never a rectangular real/imaginary pair.
